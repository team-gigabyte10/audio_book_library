|---|---|---|
| は | Topic | 私は学生です。 |
| が | Subject / existence / ability / like | 猫がいます。 |
| を | Object | 水を飲みます。 |
| に | Time / destination / existence | 7時に起きます。 |

| から | From / reason | 9時から働きます。 |
| まで | Until / to | 5時までです。 |
| も | Also / too | 私も学生です。 |

## Appendix 1: て-form Quick Chart て形早見表

| Ending | Rule | Example |
|---|---|---|
| う・つ・る | って | 買う→買って / 待つ→待って / 取る→取って |
| む・ぶ・ぬ | んで | 読む→読んで / 遊ぶ→遊んで / 死ぬ→死んで |
| く | いて | 書く→書いて ※ 行く→行って |
| ぐ | いで | 泳ぐ→泳いで |
| す | して | 話す→話して |
| Group 2 | る বাদ দিয়ে て | 食べる→食べて / 見る→見て |
| する / 来る | して / 来て | 勉強する→勉強して / 来る→来て |

## Appendix 2: ない-form Quick Chart ない形早見表

| Group | Rule | Example |
|---|---|---|
| Group 1 | শেষ u ধ্বনি → a + ない; う→わない | 書く→書かない / 買う→買わない |
| Group 2 | る বাদ দিয়ে ない | 食べる→食べない |
| Irregular | する→しない / 来る→来ない | 勉強する→勉強しない |

## Appendix 3: た-form Quick Chart た形早見表
