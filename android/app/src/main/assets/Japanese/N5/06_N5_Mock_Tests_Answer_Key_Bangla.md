## ১. Mock Test ব্যবহারবিধি

প্রথমবার বই না দেখে পরীক্ষা দিন। Vocabulary + Grammar + Reading মিলিয়ে ৬০ মিনিট সময় ধরুন। Listening-style অংশে transcript একবার জোরে পড়ে বা কাউকে পড়তে দিয়ে প্রশ্নের উত্তর দিন। শেষে উত্তর মিলিয়ে ভুলগুলো বই ২-৫ থেকে revise করুন।

> স্কোর গাইড: এই বইয়ের practice score official JLPT score নয়। 80%+ = strong; 65-79% = good but revise; 50-64% = weak areas review; 50%-এর নিচে = foundation পুনরায় পড়ুন।  

## ২. Mock Test 1

### Section A - Vocabulary

**1. 「あした」** এর অর্থ কী?  
A আজ B কাল C গতকাল D সকাল

**2. 「えき」** কী?  
A স্কুল B হাসপাতাল C স্টেশন D দোকান

**3. 「のみます」** কী?  
A খাই B পান করি C দেখি D লিখি

**4. 「やすい」** কী?  
A সস্তা B ব্যস্ত C কঠিন D বড়

**5. 「みぎ」** কী?  
A বাম B ডান C সামনে D বাইরে

**6. 「しずか」** কী?  
A শান্ত B মজার C নতুন D গরম

**7. 「まいにち」** কী?  
A প্রতি সপ্তাহ B প্রতিদিন C প্রতি মাস D এখন

**8. 「きっぷ」** কী?  
A টিকিট B ব্যাগ C চাবি D চিঠি

**9. 「あたま」** কী?  
A হাত B পা C মাথা D চোখ

**10. 「としょかん」** কী?  
A লাইব্রেরি B ব্যাংক C পার্ক D বিমানবন্দর

### Section B - Grammar

1. わたし___ がくせいです。  
A は B を C で D に

2. 7じ___ おきます。  
A へ B に C と D を

3. としょかん___ べんきょうします。  
A で B を C の D も

4. みず___ のみます。  
A は B に C を D へ

5. これは わたし___ ほんです。  
A が B の C を D で

6. きのう えいがを ___。  
A みます B みました C みません D みたい

7. この かばんは たか___です。  
A ない B くない C じゃない D ません

8. ここで しゃしんを ___もいいです。  
A とって B とり C とる D とった

9. いっしょに いき___か。  
A ません B たい C ます D でした

10. にほんへ いき___です。  
A て B たい C ない D ました

### Section C - Reading

> **Passage:** わたしは まいにち 7じに おきます。8じに でんしゃで かいしゃへ いきます。ひるは かいしゃの ちかくの レストランで ごはんを たべます。6じに うちへ かえります。  

1. কয়টায় ওঠে?  
A 6টা B 7টা C 8টা D 9টা

2. কীভাবে কোম্পানিতে যায়?  
A বাস B গাড়ি C ট্রেন D হেঁটে

<!-- page 5 -->

3. দুপুরে কোথায় খায়?  
A বাসায় B কোম্পানির কাছে রেস্টুরেন্টে C পার্কে D স্টেশনে

4. কয়টায় বাসায় ফেরে?  
A 5টা B 6টা C 7টা D 8টা

### Section D - Listening-style

> **Script 1:** A: なんじに えきで あいますか。 B: ごご 3じは どうですか。 A: 3 じは ちょっと…。4じは? B: いいですよ。  

Q1. তারা কয়টায় দেখা করবে? A 3টা B 4টা C 5টা D সকাল 4টা

> **Script 2:** A: あした どこへ いきますか。 B: あさは びょういんへ いきます。ごごは うちに います。  

Q2. সকালে কোথায় যাবে? A স্কুল B দোকান C হাসপাতাল D বাসা

## ৩. Mock Test 2

### Section A - Vocabulary

1. 「さかな」 কী?

A মাছ B মাংস C ডিম D সবজি

2. 「ゆうびんきょく」 কী?

A ব্যাংক B ডাকঘর C হাসপাতাল D স্টেশন

3. 「おそい」 কী?

A দ্রুত B দেরি/ধীর C লম্বা D পুরোনো

4. 「げんき」 কী?

A অসুস্থ B সুস্থ/চনমনে C ব্যস্ত D বিখ্যাত

5. 「かえります」 কী?

A ফিরি B আসি C যাই D বসি

6. 「あめ」 কী?

A তুষার B বৃষ্টি C বাতাস D আকাশ

7. 「ひだり」 কী?

A ডান B বাম C ওপর D নিচ

8. 「しゅくだい」 কী?

A পরীক্ষা B প্রশ্ন C হোমওয়ার্ক D উত্তর

9. 「かします」 কী?

A ধার নিই B ধার দিই C কিনি D বিক্রি করি

10. 「いくら」 কী জিজ্ঞেস করে?  
A কে B কোথায় C কত দাম D কখন

### Section B - Grammar

1. ねこは つくえの した___ います。  
A で B に C を D と

2. バス___ がっこうへ いきます。  
A で B を C と D の

3. パン___ たまごを たべます。  
A から B と C に D へ

4. きょうは さむ___です。  
A い B くない C かった D じゃない

5. きのうは さむ___です。  
A い B くない C かった D でした

6. この まちは しずか___ きれいです。  
A で B に C を D へ

7. もう ごはんを ___。  
A たべます B たべました C たべません D たべたい

8. まだ しゅくだいを ___。  
A します B しました C していません D したい

9. ねる___ はを みがきます。  
A まえに B あとで C から D まで

10. ごはんを たべた___ べんきょうします。  
A まえに B あとで C とき D だけ

### Section C - Reading

> **Passage:** きょうは どようびです。あさ そうじを しました。それから スーパーへ いって、やさいと くだものを かいました。ごごは うちで にほんごを べんきょうします。よるは ともだちと えいがを みます。  

1. আজ কী বার?  
A শুক্রবার B শনিবার C রবিবার D সোমবার

2. সকালে প্রথমে কী করেছে?  
A পড়াশোনা B পরিষ্কার C কেনাকাটা D সিনেমা

3. সুপার থেকে কী কিনেছে?  
A মাছ-মাংস B বই C সবজি-ফল D পোশাক

4. রাতে কার সাথে সিনেমা দেখবে?  
A পরিবার B শিক্ষক C বন্ধু D একা

### Section D - Listening-style

> **Script 1:** A: すみません。この かばんは いくらですか。 B: 2500 えんです。 A: じゃあ、これを ください。  

Q1. ব্যাগের দাম কত? A 1500 B 2000 C 2500 D 3000

Q2. B কখন যেতে পারবে? A আজ B কাল C পরশু D কখনও না
